# Metrics Computation & Benchmark Protocol

CHROMA follows the benchmark protocol of [Raising the Bar of AI-generated Image Detection with CLIP](https://github.com/grip-unina/ClipBased-SyntheticImageDetection) for evaluating cross-generator generalization.

The metrics system relies on a metadata CSV to pair synthetic generators with their corresponding real-image reference sets (e.g., `StyleGAN2` vs. `FFHQ-Real`).

## 1. Metadata Format

To compute generator-aware metrics (like average AUC across different families), you need a metadata CSV file (passed via `heldout_meta_csv_path` in config).

**Format Requirements:**
*   `filename`: Relative path to the image.
*   `typ`: String identifier for the source.
    *   **Real images** must start with `real`.
    *   **Synthetic images** are identified by their generator name.
    *   **Pairing**: Real and synthetic sources are paired by the suffix after `@`.
        *   Example: `real@ffhq` is the negative class for `stylegan2@ffhq`.
        *   Example: `real@coco` is the negative class for `dalle2@coco`.

**Example `heldout_meta.csv`:**
```csv
filename,typ
real_ffhq/001.png,real@ffhq
real_ffhq/002.png,real@ffhq
stylegan2_ffhq/001.png,stylegan2@ffhq
dalle2_coco/001.png,dalle2@coco
real_coco/001.png,real@coco
```

## 2. Computing Metrics Scripts

We provide standalone scripts in the `metrics/` folder to compute results on standard test sets after running inference.

### 2.1 Commercial Tools Evaluation

To evaluate on the Commercial Tools benchmark (DALL-E 2, DALL-E 3, Midjourney, Adobe Firefly):

1.  **Generate Predictions**: Run `inference.py` on the commercial tools dataset to produce a results CSV.
2.  **Compute Metrics**:

```bash
uv run python metrics/commercial_tools.py \
  --in_csv data/commercial_tools.csv \
  --out_csv results_commercial.csv \
  --metrics auc \
  --save_tab results_commercial_table.csv
```

*   `--in_csv`: The ground truth metadata CSV (provided in `data/commercial_tools.csv`).
*   `--out_csv`: Your prediction CSV generated by `inference.py`.
*   `--metrics`: Metric to compute (`auc` or `acc`).
*   `--save_tab`: (Optional) Path to save the detailed results table.

### 2.2 Standard Test Set Evaluation

To evaluate on the broader test set covering GANs and Diffusion models:

```bash
uv run python metrics/test_set.py \
  --in_csv data/test_set.csv \
  --out_csv results_test.csv \
  --metrics auc \
  --save_tab results_test_table.csv
```

## 3. Data Loading Implementation

The data loading logic is handled in `src/chroma/data/`:

*   **`datamodule.py`**:
    *   `ImageListsDataModule`: Main entry point. Manages train/val/test splits.
    *   **Weighted Sampling**: Can balance batches by class (`real` vs `fake`) or by source (`real:ffhq`, `gen:sdxl`) to prevent dominant generators from biasing the training.
*   **`datasets.py`**:
    *   `collect_image_paths`: Recursively finds images in directories.
    *   `ImagePathsDataset`: Simple `(image, label, path)` dataset compatible with the metadata matching system.
